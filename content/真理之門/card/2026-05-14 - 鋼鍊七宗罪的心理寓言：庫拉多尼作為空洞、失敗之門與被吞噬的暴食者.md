# 筆記卡
- 類型：角色分析筆記
- 角色：庫拉多尼（Gluttony／暴食）
- 作品：《鋼之鍊金術師》
- 主題：空洞、飢餓、失敗之門與被吞噬的命運
- 核心判斷：庫拉多尼不是單純愛吃的怪物，而是一個從誕生起就帶有缺陷、永遠填不滿的存在。他的暴食不是享受，而更像是一種無限匱乏的具象化。

# 角色定位
- 庫拉多尼是父親大人製造真理之門的失敗品。
- 他體內擁有一個近乎無限大的額外空間，位於真理之門與現實空間的夾縫之中，因此能吞下幾乎任何東西。
- 從設定上看，他一開始就不是完整存在，而是失敗本身被保留下來的生命形式。

# 角色特質
- `永不滿足的飢餓`：庫拉多尼看到什麼都想吃，卻從未真正感到飽足。
- `單純性`：他不像其他人造人那樣算計、辯證或自我修飾，而是以近乎幼兒或原始生物般的直接性存在。
- `靈敏嗅覺`：他依靠氣味辨認目標，也讓他更接近純本能驅動的生命型態。
- `依附傾向`：他對拉斯多具有明顯特殊情感，顯示其雖本能化，仍保有強烈依附需求。

# 象徵分析
- `暴食不是享樂，而是空洞`：庫拉多尼真正的本質不是喜歡吃，而是怎麼吃都填不滿。
- `失敗品的結構`：他體內的額外空間是失敗的真理之門夾縫，象徵他本身就是一個裂口、一個無法閉合的缺洞。
- `永遠的匱乏`：因此，暴食在他身上不是欲望的擴張，而是缺失的無限延長。
- `與拉斯多的並置`：暴食與色慾在現實中常作為感官享樂的並行象徵，而在作品裡兩者也總是成對出現，形成相互映照。

# 角色命運
- 庫拉多尼最終被重傷的普萊德吞食，作為賢者之石的補給。
- 這一結局帶有高度反諷：以吞食為存在方式的暴食，最後反而成為被吞食的對象。
- 從象徵上看，這像是在說，若一個存在始終只懂得吞入，而無法轉化、理解或超越匱乏，那麼他最終也可能被更大的欲望所吞沒。

# 心理與哲學延伸
- `本能型存在`：庫拉多尼不像古利德、恩維那樣具有高度自我反思，因此他或許是最接近純本能驅動的人造人。
- `幸福的悖論`：若沒有太多思考與自我意識，痛苦未必被感受得那麼複雜；但相對地，他也幾乎沒有真正自我完成的可能。
- `被吃掉的暴食者`：這使他的結局不只是悲慘，也像是作品對純粹本能存在的一種殘酷回答。

# 可直接放進分析的句子
- 庫拉多尼作為暴食的化身，其核心並不只是食量驚人，而是一種永遠無法被填補的存在性匱乏。
- 他體內作為失敗真理之門的夾縫空間，使其從誕生之初便帶有裂口與缺陷，因此其吞食行為不應只被理解為欲望表現，而更應被理解為對內在空洞的反覆填補嘗試。
- 也因此，庫拉多尼的悲劇不在於他太想吃，而在於他根本不可能吃到滿足。
- 其最終被普萊德吞食的結局，形成強烈反諷：暴食者最後反而淪為他者的食糧，象徵純粹本能驅動的生命形式終將被更大的吞噬邏輯所回收。

# 一句話濃縮
庫拉多尼最可悲的地方，不是他吃太多，而是他從一開始就是一個怎麼吞都填不滿的缺口。
