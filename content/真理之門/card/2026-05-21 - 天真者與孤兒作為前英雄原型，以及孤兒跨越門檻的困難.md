# 類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019。

# 主題
天真者與孤兒作為前英雄原型，以及孤兒跨越門檻的困難

# 關鍵概念
前英雄原型、天真者、孤兒、門檻、英雄之旅、引導與幫助

# 核心摘記
- Pearson 指出，天真者與孤兒都屬於「前英雄」原型。
- 天真者通常會在生命自然推動下，逐步脫離原有幻想，被現實帶出原初的保護狀態。
- 但孤兒不同。孤兒由於深受失落、無力與絕望影響，比其他原型更需要外在幫助，才能真正跨越門檻，踏上英雄之旅。
- 換言之，孤兒不是不會成長，而是其從受創狀態進入行動狀態的轉換，往往格外艱難，也特別需要引導、支撐或陪伴。

# 可引用分析
從 Pearson 這段論述可見，天真者與孤兒之所以被稱為「前英雄」原型，在於它們都尚未真正進入主動開展世界的英雄位置。前者仍停留在受保護的幻想中，後者則停留在幻想破裂後的受傷與無力中。

兩者的差異在於，天真者的幻滅往往會隨生命推進自然到來，而孤兒在失去原有安全感之後，卻不一定能自然走向下一步。因為其問題不只是看見現實的殘酷，而是如何在經歷背叛、遺棄或失落之後，仍然相信自己可以繼續活下去、繼續前進。

也因此，孤兒比其他原型更需要幫助。這裡的幫助不一定只是物質援助，而更可能是來自導師、夥伴、愛、秩序或希望，使其有能力跨過那道心理門檻，從被動承受命運的人，轉為真正踏上旅程的人。

# 可直接放進論文的句子
- Pearson 指出，天真者與孤兒都屬於前英雄原型，意味著它們仍停留在尚未真正進入主動成長與世界實踐的位置。
- 相較之下，天真者較容易在生命自然推動中脫離幻想，而孤兒則因深受失落、絕望與無力感影響，更需要幫助，才能跨越門檻踏上英雄之旅。
- 從這個角度來看，孤兒原型的關鍵不只在於其遭遇創傷，而在於其是否能獲得足夠支持，從受傷狀態轉向行動與成長。
- 因此，文本中若角色處於強烈的孤兒位置，則其後續是否能獲得導引、希望與關係支撐，往往正是其能否真正進入英雄旅程的關鍵條件。
