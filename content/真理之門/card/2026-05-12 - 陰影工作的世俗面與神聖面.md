# 資料來源
- 書名：`《擁抱陰影：從榮格觀點探索心靈的黑暗面》`
- 篇名：鐘穎，〈擁抱陰影〉
- 位置：推薦序二，頁 19-20
- 出版資訊：徐曉珮譯，初版，臺北市：心靈工坊文化事業股份有限公司，2021。
- 性質：學術／心理學書籍推薦序

# 一句話結論
陰影工作不只關乎自我整合，也關乎停止把黑暗投射到他人身上。

# 重點摘要
- 陰影工作同時具有世俗面與神聖面。
- 世俗面在於：若個體不處理自身陰影，黑暗便會被投射到家人、朋友、同事、異己與群體身上，進而合理化敵意、排斥與暴力。
- 神聖面在於：陰影工作是個體化與完整開展自我的起點與終點，最終指向一種超越主客與得失對立的觀看方式。
- 因此，陰影整合不只是個人心理修補，也具有倫理、社會與群體層面的意義。

# 核心概念
- `陰影工作`：從認出、承擔到整合陰影，而不是把它外包給世界。
- `投射`：未被整合的黑暗會被安放到他者身上，形成敵意與清算邏輯。
- `世俗面`：確保人性品質、合作基礎與社會和平。
- `神聖面`：通往個體化、完整與更高層次視角的路徑。

# 對我有用的應用情境
- 可用來說明陰影整合不只是心靈議題，也是倫理與社會議題。
- 可直接作為《鋼鍊》斯卡角色弧線的分析框架。
- 可補進 `原型／陰影／個體化` 理論段落，強化陰影工作的雙重性質。
