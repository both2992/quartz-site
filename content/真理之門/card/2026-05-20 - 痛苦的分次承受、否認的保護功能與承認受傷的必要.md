# 資料類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019，頁64。

# 主題
痛苦的分次承受、否認的保護功能與承認受傷的必要

# 關鍵概念
痛苦、磨難、否認、分次承受、承認受傷、轉化信號

# 核心摘記
- Pearson 指出，人無法一次承受全部的痛苦與磨難，因此成長往往不可能一步完成。
- 否認並不完全是負面的，它有保護功能，使人不致於一次被所有痛苦壓垮。
- 但這種保護不是終點。每一次逐漸覺察到的痛苦，都可被視為推動生命改變的信號。
- 真正的功課不在逃避，而在逐步認識痛苦、承認痛苦，並承認自己確實受了傷。

# 可引用分析
這段很適合拿來理解創傷為什麼常常不是一次被看見，而是分次被承認。否認不只是逃避，有時也是讓人暫時活下去的方式。真正的轉化不是立刻全面接受一切，而是在準備好之後，一點一滴把原本承受不了的痛苦帶進意識。

# 與《鋼鍊》的關聯
這段非常適合連到愛德華燒掉家的行動。燒家未必只是切斷後路，也可以理解為愛德在還無法全面承認失去母親、人體鍊成失敗與家庭崩解時，先用一個激烈而具體的動作讓自己往前移動。這表示他的成長不是瞬間完成，而是在否認與承認之間反覆推進。

# 可直接放進論文的句子
- Pearson 指出，個體往往無法一次承受全部痛苦，因此心理上的否認在某種程度上具有保護功能，使人得以分階段面對傷害與失落。
- 從這個角度來看，成長並不是立即全面接受痛苦，而是透過逐步覺察、逐步承認受傷的方式，慢慢走向轉化。
- 若應用於《鋼之鍊金術師》，愛德華燒掉故居的舉動，便可被理解為其尚未能全面承認家庭崩解與鍊成失敗之創傷時，所做出的激烈但具有心理保護性的前進動作。

# 一句話濃縮
否認不一定只是逃避，它有時是人暫時活下去的方式；真正的成長，則是在準備好之後，終於承認自己真的受了傷。
