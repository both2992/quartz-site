# 資料來源
- 書名：`《擁抱陰影：從榮格觀點探索心靈的黑暗面》`
- 位置：正文，頁 79-80
- 出版資訊：羅伯特・強森著，徐曉珮譯，初版，臺北市：心靈工坊文化事業股份有限公司，2021。
- 性質：心理學理論書籍

# 一句話結論
陰影若未被覺知與內化，就會被投射到外部世界，而人格也因此無法完整。

# 重點摘要
- 強森指出，若人無法有意識且帶著尊重地讓陰影顯現，陰影就會落到他人或外在事物上，使個體逃避對自身黑暗的責任。
- 這種投射不只屬於個人心理，也會形成群體與文化層次的敵我結構。
- 現代人雖不再以中世紀方式生活，卻仍習慣透過電影、小說、災難新聞、犯罪想像與恐懼敘事，把陰影外移出去。
- 但當陰影總被投入外部，而不是被內化為人格整合的一部分時，完整便不可能達成。
- 投射比同化容易，因此陰影工作真正困難之處，正在於把黑暗重新認回自身。

# 核心概念
- `陰影投射`：把自己的黑暗面安放到別人或外部世界上。
- `同化`：承擔並整合原本外移的黑暗，使其成為人格的一部分。
- `覺知`：避免投射的關鍵條件，也是整合的起點。
- `人格完整`：不是沒有黑暗，而是黑暗不再完全被外包給世界。

# 對我有用的應用情境
- 可補進陰影理論段落，說明陰影為何難以整合。
- 可支撐分析文本中的替罪羊、敵我投射、群體仇恨與暴力機制。
- 可有限度地連到正念中的覺察概念，但需補理論來源。

# 今天可執行的下一步
- 在理論基礎中補上一段：投射總比同化容易，因此陰影工作的起點在於覺知。
