# 資料類型
理論書籍筆記＋文本延伸

# 來源
Mark, Margaret；Pearson, Carol S. 著，許晉福、戴至中、袁世珮譯，《很久很久以前：以神話原型打造深植人心的品牌》，臺北：麥格羅‧希爾，2002，頁108、110、111。

# 主題
探險家／流浪者原型的體制態度、親密焦慮與組織模式

# 關鍵概念
探險家、流浪者、體制批判、親密威脅、個體性、平等機會

# 核心摘記
- 探險家通常對體制抱持批判態度，但不像英雄原型那樣直接投入改造，而更傾向依照自身人生觀生活。
- 親密感對探險家來說，可能威脅自我，因此他們在深層關係裡常顯得笨拙或保持距離。
- 探險家式的組織重視個體性，不強調僵固規則與階級決策，也傾向追求較高的機會平等。

# 可引用分析
這段很適合補強流浪者原型的成熟面向。探險家不是單純遠離世界，而是在維護自我完整性的前提下，慢慢學習如何有限度地介入世界與關係。因此，他對制度常保持批判距離，對親密也會顯得遲疑，但這不代表他沒有關心，而是必須先確保自己不會被吞沒。

# 與霍恩海姆的關聯
霍恩海姆很適合放在這條線上理解：他對國家體制保持距離，對親情顯得笨拙，在地道分配路線時又採取較重視個體能力與平等分工的方式。這些都很符合成熟中的流浪者／探險家特徵。

# 可直接放進論文的句子
- Mark 與 Pearson 指出，探險家原型通常對體制抱持批判態度，但不一定積極改造世界，而更常選擇依照自身人生觀生活。
- 此外，親密感對探險家而言可能構成對自我的威脅，因此其在深層關係中往往顯得遲疑、笨拙或保持距離。
- 若以此觀點分析《鋼之鍊金術師》的霍恩海姆，則其對國家體制的疏離、對家庭情感的笨拙，以及其較重視個體能力與平等分工的行動方式，都顯示其帶有鮮明的流浪者／探險家原型特徵。

# 研究用途
- 很適合補進霍恩海姆角色總卡。
- 也能補強你前面關於流浪者從獨立走向成熟親密的論述。

# 一句話濃縮
探險家不是不在乎世界與他人，而是總得先保住自己，才敢慢慢走向世界與他人。
