# 資料來源
- 書名：《擁抱陰影：從榮格觀點探索心靈的黑暗面》
- 作者：羅伯特・強森（Robert A. Johnson）
- 譯者：徐曉珮
- 出版社：心靈工坊文化事業股份有限公司
- 頁碼：第88頁

# 一句話結論
陰影不只藏黑暗，也可能藏著尚未內化的光，因此英雄崇拜與敵意有時都指向自己還沒活出的力量。

# 重點摘要
- 強森指出，陰影不只是個體不願承認的黑暗部分，也可能是把自身最好的一部分投射到他人身上。
- 所謂英雄崇拜，就是一種正向特質的陰影投射：個體尚未能活出的能力、勇氣或格局，被暫時安放在偶像身上。
- 成長的關鍵不在永遠仰望偶像，而在於逐步把這些特質重新內化，讓「今天崇拜的力量」成為「明天自己的能力」。
- 這意味著，角色所羨慕、敵視、無法忽視的對象，未必只是外部對手，也可能承載了他尚未整合的潛能。

# 核心概念
- `陰影中的黃金`：陰影不只容納黑暗，也容納被自我排拒的優秀特質。
- `英雄崇拜`：將自身尚未活出的能力投射到外在偶像身上。
- `內化`：停止把力量留在外部對象，改為收回並發展成自己的能力。
- `鏡像敵意`：有時角色最看不順眼的人，正承載了自己尚未接納的亮面潛能。

# 對我有用的應用情境
- 可直接拿來分析《鋼鍊》中的成對角色，特別是古利德／姚麟、恩維／愛德華這種同時具有敵意、羨慕與吸收關係的組合。
- 可補強「文本個體化歷程」的論點，因為角色間的投射與內化不只是單點成長，而會共同推進整體文本的轉化。
- 也適合處理角色之間的英雄崇拜、鏡像對位、羨慕性敵意與潛能召喚。

# 今天可執行的下一步
