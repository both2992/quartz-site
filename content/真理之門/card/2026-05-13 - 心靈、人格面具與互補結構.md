# 資料來源
- 理論書籍：《榮格論心理類型》
- 作者：卡爾・榮格（Carl G. Jung）
- 譯者：莊仲黎
- 出版資訊：臺北市：商周出版／家庭傳媒城邦分公司，2017
- 頁碼：p.517-p.523

# 一句話結論
人格面具愈鮮明，內在心靈愈可能以互補、投射與依附形式回返；強烈的愛恨關係，常不只是人際互動，也涉及內在心靈意象的外投。

# 重點摘要
- 榮格區分「心理」與「心靈」：前者是全部意識與無意識心理過程的總和，後者則是具有清楚界分的特定功能綜合體。
- 個體即使在正常情況下，也常在不同情境中呈現雙重性格，這並不單純是虛偽，而與外在態度與內在態度的分化有關。
- 榮格把適應社會與外界而形成的外在態度稱為「人格面具」，它不等於真正的個體性。
- 與人格面具相對的，是個體對內在無意識內容的態度，也就是「心靈」；二者通常呈互補關係。
- 當個體過度認同人格面具時，心靈會停留在無意識中，並以「心靈意象」的形式投射到具體人物上，造成強烈的愛、恨、恐懼或命運性感。
- 心靈意象若未被辨識，便容易使人將他者誤認為自己內在未整合部分的真實承載者，形成依附、拯救幻想或悲劇性關係。

# 核心概念
- `人格面具（Persona）`：對外適應的功能性面具，不等於真正的個體性。
- `心靈（Seele）`：與內在無意識內容對應的內在態度。
- `心靈意象（Seelenbild）`：呈現心靈的無意識人物意象，常成為投射核心。
- `互補結構`：外在態度愈偏向某端，內在愈可能發展出相反傾向。
- `阿尼瑪／阿尼姆斯`：榮格用來說明心靈意象在性別化結構中的歷史術語。

# 對我有用的應用情境
- 分析角色在公共身分與私密內在之間的落差。
- 分析帶有命運感、依附性、拯救幻想或強烈敵意的人際關係。
- 補強「原型不是靜態分類，而是具有補償與互補結構」的理論線。
- 作為《鋼鍊》角色鏡像、對位、依附與投射分析的理論支點。

# 今天可執行的下一步
- 把《鋼鍊》中一組最強烈的雙人關係，拆成「人格面具／內在態度／投射對象」三欄做對照。
- 在論文理論基礎中先界定：這裡使用的重點是心靈意象與投射機制，而非把阿尼瑪／阿尼姆斯直接轉成當代性別理論。
