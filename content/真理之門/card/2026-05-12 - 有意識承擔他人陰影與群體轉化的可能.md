# 資料來源
- 書名：`《擁抱陰影：從榮格觀點探索心靈的黑暗面》`
- 位置：正文，頁 84-85
- 出版資訊：羅伯特・強森著，徐曉珮譯，初版，臺北市：心靈工坊文化事業股份有限公司，2021。
- 性質：心理學理論書籍

# 一句話結論
在特定情境下，有意識地承接他人陰影，可能讓整個關係場域一起走向轉化。

# 重點摘要
- 強森指出，一般情況下人需要阻擋他人的陰影投射，但在某些特殊情境下，若能有意識地承擔他人的陰影，反而可能帶來正面結果。
- 日本漁村禪師故事顯示：當一個人不急於辯解或反擊，而是留出空間，投射者便可能被迫回頭面對自己的黑暗來源。
- 這種承擔不是被動受害，而是建立在相當程度的陰影內化與沒有報復意圖之上的成熟能力。
- 這也意味著，轉化不一定只在單一角色身上發生，而可能使整個關係網絡中的多個角色同時面對並修正自身問題。

# 核心概念
- `有意識承擔`：在足夠內在穩定下，暫時承接他人投射而不立刻反擊。
- `等待的力量`：不急於澄清，使投射有機會自行顯影並回返本源。
- `群體式個體化`：單一事件促使多個角色同步面對陰影與責任的歷程。
- `關係場中的轉化`：原型與陰影在群體互動中彼此牽動、共同完成變化。

# 對我有用的應用情境
- 可支撐分析文本中的重大衝突事件如何同時改變多名角色。
- 可作為「文本不只是容器，而是整體性心靈結構」的補充理論。
- 適合用來分析群像作品中的集體成長與多重弧線互動。

# 今天可執行的下一步
