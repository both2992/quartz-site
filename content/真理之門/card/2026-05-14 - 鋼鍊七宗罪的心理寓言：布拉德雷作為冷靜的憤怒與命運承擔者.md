# 筆記卡
- 類型：角色分析總卡
- 角色：金格・布拉德雷／拉斯（Wrath／憤怒）
- 作品：《鋼之鍊金術師》
- 主題：冷靜的憤怒、極端控制與命運承擔
- 核心判斷：布拉德雷是七宗罪中最矛盾、也最成熟的一個。他並非情緒失控式的憤怒，而是將憤怒壓縮成極端冷靜、極端精準、極端致命的生命形式，因此他也成為作品中最接近帶著怒火活得像刀刃的存在。

# 角色定位
- 布拉德雷原本是人類，從小作為大總統候補接受嚴苛、系統化的精英訓練。
- 在體能與精神達到巔峰時，被注入賢者之石，經歷劇烈排斥後成為唯一存活者，並因此成為憤怒的人造人。
- 他也是七宗罪中極特殊的一位：會老、無再生能力、擁有人類婚姻與情感，同時又具備非人級別的戰鬥力與意志強度。

# 能力與象徵
- `最強之眼`：左眼腐爛後獲得近乎能追上子彈的眼力，能洞穿對手的行動軌跡與弱點。
- `戰鬥方式`：以敏銳視覺、極致反應與高超刀術進行戰鬥，幾乎在單挑中無敵。
- `無再生卻最強`：他是少數沒有再生能力卻仍能壓制一切敵人的人造人，顯示其力量更建立於技巧、判斷與意志，而不是單純耐久。
- `憤怒的形式`：布拉德雷的憤怒不是外顯咆哮，而是一種冷靜、壓縮、凝聚到刀鋒上的破壞力。

# 角色特質
- `表面和藹，實則冷酷`：他平時總是笑面迎人，但這不代表沒有怒，而是將怒意完全收束在控制與行動之中。
- `高度自制`：他的可怕之處正在於憤怒沒有讓他混亂，反而讓他更精準、更狠決。
- `不為自己辯解`：他接受自己被安排的人生，也不逃避其作為國家暴力象徵的身分。
- `人性殘留`：儘管身為人造人，他對妻子懷有真情，對自己所經歷的一切也保持某種坦然承擔。

# 心理與象徵分析
- `憤怒不是爆發，而是佔據`：布拉德雷不是原本人性裡自然生出的憤怒，而是被注入、被迫承受、最終又被完全內化的憤怒。
- `冷靜型怒火`：這使他成為一種很特殊的怒之樣態，不是歇斯底里的暴怒，而是理性與暴力融合後的絕對執行。
- `自傷性`：正如憤怒中的人會在傷害他人的同時傷害自己，布拉德雷即使斷臂、重傷，仍以牙咬刀繼續戰鬥，將這種自傷性推到極致。
- `命運加速器`：憤怒不只是他的力量來源，也加速了他的生命耗損與最終毀滅。

# 與斯卡的對照
- 由斯卡殺死布拉德雷具有高度象徵意義。
- 斯卡原本也是被滅族之恨與怒火驅動的人，而布拉德雷則是被制度、力量與命運強行塑造成的憤怒本身。
- 因此，斯卡擊倒布拉德雷，不只是打倒敵人，也象徵他開始終結自己長期被怒火支配的生命狀態。
- 換言之，斯卡殺死憤怒，同時也是向自身憤怒做出最後交代。

# 角色弧線
- 前期：作為完美總統與最強人造人，代表國家秩序與暴力的冷酷頂點。
- 中期：逐步顯示其不只是被操控的工具，而是對自身命運有高度自覺的行動者。
- 後期：在連番戰鬥後仍不敗，最終在血泊中迎來死亡，並以近乎平靜的姿態接受終局。
- 結尾意義：他並非懺悔而死，而是帶著對人生的承認死去，這使他的死亡帶有一種罕見的尊嚴。

# 可直接放進分析的句子
- 布拉德雷作為憤怒的化身，其特殊之處不在情緒失控，而在於將憤怒壓縮成一種高度冷靜、精準且致命的存在形式。
- 他雖以人類為基礎被製造成為人造人，卻並未完全失去人的情感與關係能力，反而因此成為七宗罪中最複雜的一個：既是暴力機器，也是有情感、有執著、有命運感的人。
- 正因如此，布拉德雷的死亡並不只是反派落幕，而更像是一種怒火在極限燃燒後的安靜熄滅。
- 而由斯卡親手終結布拉德雷，則進一步使這場死亡獲得象徵意義：迫害伊修瓦爾的國家暴力之怒，最終由曾被怒火吞噬的伊修瓦爾倖存者親手平息。

# 一句話濃縮
布拉德雷最可怕的地方，不是他憤怒，而是他能帶著憤怒微笑、冷靜、精準地活完自己的一生。
