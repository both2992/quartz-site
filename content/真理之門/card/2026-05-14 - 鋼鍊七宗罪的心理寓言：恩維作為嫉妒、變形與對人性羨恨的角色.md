# 筆記卡
- 類型：角色分析總卡
- 角色：恩維（Envy／嫉妒）
- 作品：《鋼之鍊金術師》
- 主題：嫉妒、變形、自卑與對人性的羨恨
- 核心判斷：恩維是《鋼鍊》中最能把嫉妒放大到極致的角色。他不是單純厭惡人類，而是在持續蔑視、傷害與玩弄人類的過程中，暴露出自己對人類情感連結、韌性與彼此扶持能力的深層妒羨。

# 角色定位
- 恩維作為嫉妒的化身，長期以高傲、輕蔑與殘酷的姿態俯視人類。
- 他看似總是把人類當成渺小、愚蠢、任性的螻蟻，但越是如此，越顯示其視線無法離開人類。
- 因此，恩維的真正核心不是單純仇恨，而是一種無法承認的羨慕與自卑。

# 能力與象徵
- `變形能力`：恩維能變化成任何人的外貌、聲音與舉止，擅長滲透、欺瞞與暗殺。
- `原型姿態`：其真正本體是醜陋、蟲狀、掛滿腐爛人屍的巨大怪物，與其平時可變幻的美麗或正常外貌形成巨大反差。
- `象徵意義`：這使恩維成為極佳的嫉妒象徵。嫉妒總想變成別人、偽裝成更好看的樣子、透過他人形象膨脹自己，但其核心卻往往源自深層的不滿與羞恥。
- `膨脹性`：恩維能瞬間巨大化，也可被視為嫉妒被刺激後迅速膨脹的具象化。

# 角色特質
- `尖酸與刻薄`：他總以惡語、嘲諷、玩弄情感為樂。
- `情感破壞者`：他特別喜歡對準人類最珍視的關係下手，例如家庭、友情、信任與愛。
- `自命高人一等`：他以居高臨下的姿態否定人類，但這種姿態本身就是防禦性的。
- `最像人的怪物`：恩維不像古利德那樣走向成為更像人的完成，而是像現實中許多人類那樣，把嫉妒、自卑、面子與惡意推到極致。

# 關鍵情節
- `挑起伊修瓦爾殲滅戰`：偽裝成軍人射殺伊修瓦爾平民，引爆種族滅絕與戰爭，顯示其善於操弄集體仇恨。
- `殺害休斯`：偽裝成休斯的妻子，使休斯在情感猶疑中被殺，這一行為超越了完成任務，而更接近對人類感情的惡意玩弄。
- `與愛德、馬斯坦古對決`：馬斯坦古以焰之鍊金術燒去他大部分賢者之石，而愛德最後看穿其嫉妒本質，成為恩維真正崩潰的關鍵。

# 心理分析
- `投射`：恩維不斷把自己對人類羈絆的渴望轉化成攻擊，因此越恨人類，越說明他越離不開人類。
- `羨恨結構`：他不是單純想成為人類，而是無法忍受人類竟然擁有自己所沒有的東西，例如彼此扶持、即使脆弱仍繼續前進的能力。
- `自卑的傲慢`：他高傲地說自己不可能嫉妒人類，但正因為極端否認，才顯出其最深層的自卑。
- `嫉妒與羞恥`：恩維最後不是因快死而崩潰，而是因為被愛德看穿、被人類理解，這對他而言比死亡更羞恥。

# 本體象徵
- 恩維原型是一條醜陋的蟲，這與其長期蔑視人類的語言形成反差。
- 這個設計很有象徵性：嫉妒的人常以為自己在看低別人，實際上卻被自己的渺小、自卑與醜陋困住。
- 他不停擴張自己、模仿別人、變成別人，卻無法真正成為自己羨慕的那種存在。

# 結局意義
- 恩維最終拔出自己僅剩的賢者之石，捏碎，自盡而死。
- 這一死不是簡單的失敗，而是他在終於知曉自己真正嫉妒之物後，無法承受那種被看透的羞恥。
- 也因此，他的死亡可以被理解為一種極端的內化時刻：他終於不再把痛苦外推，而是第一次直面自己的本質。
- 嫉妒在他身上最後不是被戰勝，而是被揭露；而揭露本身就足以使其崩解。

# 可直接放進分析的句子
- 恩維的角色意義，不在於單純作為七宗罪中的反派，而在於他將嫉妒這一情感推演到極致，使其成為一種兼具自卑、惡意與羞恥的複合性心理結構。
- 他越是蔑視人類、反覆強調人類的愚蠢與渺小，越顯示其真正無法忍受的，正是人類所擁有而自己無法擁有的情感連結與彼此扶持能力。
- 因此，恩維對人類的敵意不應只被理解為仇恨，而更應被理解為一種被壓抑、被否認的羨慕。
- 他最終的自盡之所以動人，不在於死亡本身，而在於他第一次被迫直視：自己一直嫉妒的，正是自己長久以來最想否定的人性之光。

# 一句話濃縮
恩維最悲哀的地方，不是他像怪物，而是他明明最羨慕人類，卻只能用傷害人類來掩飾這件事。
