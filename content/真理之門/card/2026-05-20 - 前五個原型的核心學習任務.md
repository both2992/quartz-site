# 資料類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019，頁20。

# 主題
前五個原型的核心學習任務

# 關鍵概念
天真者、孤兒、流浪者、鬥士、殉道者、信任、哀傷、真實自我、影響世界、愛與放下

# 核心摘記
- Pearson 以發展歷程角度指出，英雄在不同原型階段有不同的學習任務。
- 天真者 學習的是 信任。
- 孤兒 學習的是 哀傷。
- 流浪者 學習找出並界定真實的自己。
- 鬥士 要肯定這個真實自我，並進一步以此影響、改變世界。
- 殉道者 則學習去愛、去承諾，並最終放下執著。

# 可引用分析
這段很重要，因為它把原型從靜態分類轉成一條成長路徑。原型的關鍵不只是角色「像哪一類」，而是角色當下正在學哪一門生命功課。從信任、哀傷、自我尋找、自我肯定，到愛與放下，這些原型其實標示的是一條逐步深化的人格發展順序。

# 可直接放進論文的句子
- Pearson 指出，英雄在不同原型階段各有其核心學習任務：天真者學習信任，孤兒學習哀傷，流浪者學習找出真實自我，鬥士學習肯定自我並改變世界，殉道者則學習去愛、去承諾與放下執著。
- 因此，原型並非彼此孤立的角色分類，而是一條具有內在順序的成長路徑。
- 角色分析不應只問角色屬於哪一原型，更應探問其當下正在學會什麼。

# 研究用途
- 可直接用於愛力克兄弟、斯卡、馬斯坦古等角色的階段分析。
- 很適合補強你前面關於原型是動態進程、不是靜態分類的論述。

# 一句話濃縮
原型的重點不只在「角色像誰」，而在「角色此刻正在學會什麼」。
