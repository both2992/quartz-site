# 類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019。

# 主題
英雄之輪的三重迴旋

# 關鍵概念
流浪者、孤兒、魔術師、鬥士、犧牲者、三重迴旋、原型深化

# 核心摘記
- Pearson 以「英雄之輪的三重迴旋」說明，原型不是單點分類，而是由陰影、任務與整合結果所構成的動態發展。
- 每一原型都可分成三層：
  - 初始失衡或陰影狀態
  - 中段學習任務
  - 後段較成熟的整合結果

# 原型三重結構整理
- 流浪者／明晰
  - 陰影：孤寂、疏離
  - 任務：選擇探索之旅，逃離囚牢，找到自我的寶藏
  - 整合：發現自我，並重新擁有愛與社群

- 孤兒／信任
  - 陰影：以耽溺遮掩失望
  - 任務：承認、感知痛苦，並為此哀憐
  - 整合：尋求、接受支助，接納互依的現實

- 魔術師／快樂
  - 陰影：面對陰影
  - 任務：成全自己與世界，為個人生命負責
  - 整合：覺察同步現象的神奇，尊崇自己，享受世界

- 鬥士／力量
  - 陰影：把他人異己化，不惜一切代價求取勝利
  - 任務：學習為真正的信仰、價值、自我與他人而戰
  - 整合：視堅定為人生韻律的一部分，並敬重對手

- 犧牲者／摯愛
  - 陰影：以取悅他人、慰藉他人來成就善良，甚至以傷害自己方式幫助別人
  - 任務：學習真正的奉獻與給予
  - 整合：從小我奉獻給大我的過程中找到自己

# 可引用分析
從這組整理可見，原型發展並不是由一種狀態跳到另一種狀態，而是每一原型內部本身就有一條從失衡到成熟的深化路徑。

這也意味著，角色分析不能只說某角色「是流浪者」或「是鬥士」，而應進一步辨識：他目前停留在該原型的陰影面、學習面，還是整合面。

因此，原型的真正價值不在標籤，而在於它能提供角色成長位置與轉化方向的判讀工具。

# 可直接放進論文的句子
- Pearson 所提出的「英雄之輪的三重迴旋」顯示，原型並非靜態類型，而是包含陰影狀態、學習任務與整合結果的動態發展結構。
- 從這個角度來看，角色分析不應只停留在辨認其屬於哪一原型，而更應進一步觀察其正處於該原型的哪一層次。
- 也因此，原型理論的功能不只是分類角色，更是用來判讀角色如何失衡、如何學習，以及如何逐步走向成熟整合。

# 研究用途
- 很適合補強你前面關於「原型不是靜態分類」的論述。
- 也很適合直接套用在《鋼鍊》角色：
  - 愛德可分析流浪者／鬥士的三重層次
  - 斯卡可分析孤兒／鬥士的陰影到整合
  - 霍恩海姆可分析流浪者到更成熟整合
  - 馬斯坦古可分析鬥士與犧牲者之間的推進

# 一句話濃縮
原型不是「你是誰」的標籤，而是「你正卡在哪裡、要學什麼、可能走向哪裡」的路線圖。
