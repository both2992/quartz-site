# 資料來源
- 羅伯特．強森著，徐曉珮譯，《擁抱陰影：從榮格觀點探索心靈的黑暗面》，臺北市：心靈工坊文化事業股份有限公司，2021，頁147-148。

# 一句話結論
陰影整合不是一次性的自我修補，而是持續性的日常實踐；其真正成果不是灰色妥協，而是像孔雀尾一樣，保留黑暗、光明、熱情與價值後形成的全彩整合。

# 重點摘要
- 自我與陰影的對立，是個人與社會層次都反覆出現的基本處境。
- 陰影工作需要每日進行，否則黑暗便會持續以戰爭、暴力、歧視等集體形式外溢。
- 陰影工作的第一個好處是減少對他人的投射，第二個好處是為更高層次的整體性與靈光做準備。
- 書中以煉金術四階段說明整合歷程：黑化、白化、紅化、黃化。
- 最終的完成不是把色彩攪成灰，而是形成包含一切色彩的孔雀尾。

# 核心概念
- 日常陰影工作
- 集體陰影
- 黑化／白化／紅化／黃化
- 孔雀尾
- 全彩整合

# 對我有用的應用情境
- 可作為「整合不是中和，而是更高層次平衡」的總結理論。
- 可作為《鋼鍊》與煉金術象徵系統連結的重要橋梁。
- 可用來分析文本如何保留衝突、黑暗與對立，而不把它們抹平。
