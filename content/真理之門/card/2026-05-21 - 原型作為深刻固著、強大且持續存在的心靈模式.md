# 類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019，頁25

# 主題
原型作為深刻固著、強大且持續存在的心靈模式

# 關鍵概念
榮格、原型、心靈模式、深刻固著、力量、永恆存在

# 核心摘記
- Pearson 指出，按照榮格的假設，原型是人類心靈中深刻固著的模式。
- 這些模式並非短暫或偶發，而是具有強大作用力，且長久持續存在。
- 因此，原型不只是分析角色時的分類工具，而是會實際影響人如何理解世界、如何感受、如何行動的深層心理結構。

# 可引用分析
從 Pearson 這段說明可見，原型並非外加於文本或人格之上的解釋框架，而是人類心靈本身早已存在的深層模式。正因其深刻固著且具有持續性，原型才能跨越文化與時代，反覆出現在神話、宗教、敘事與日常生活之中。

這也意味著，原型之所以能引發普遍共鳴，不只是因為它們被不斷重複使用，而是因為它們本就對應著人類共同的心理結構。換言之，人之所以能辨識某些角色、情節與象徵，不只是出於後天文化學習，也來自這些模式本身早已在心靈中佔有位置。

因此，原型理論的價值，不只在於協助分類人物，更在於說明文本如何觸及人類共同的深層經驗，並透過這些強大而持續存在的模式，產生跨文化、跨時代的說服力與感染力。

# 可直接放進論文的句子
- Pearson 指出，按照榮格的假設，原型是人類心靈中深刻固著的模式，具有強大作用力，且長久存在。
- 從這個角度來看，原型並非單純的角色分類工具，而是會持續影響人類理解世界、感受生命與組織經驗的深層心理結構。
- 也因此，原型之所以能在不同文化與時代中反覆出現，並對讀者產生普遍共鳴，正是因為它們對應的是人類共同的心靈模式，而非偶發性的文化符號。
- 原型分析的意義，便不只在辨識文本中出現了何種角色型態，更在於說明這些角色何以能觸及人類深層而持續存在的心理經驗。

# 研究用途
- 很適合補強你前面關於「原型不是靜態分類，而是深層心理結構」的論述。
- 也可和你先前整理的榮格、原初意象、集體無意識、故事共鳴等筆記互相銜接。
- 若你之後要寫《鋼鍊》角色與原型之所以具有普遍感染力，這張卡很好用。

# 一句話濃縮
原型之所以有力量，不是因為它常被使用，而是因為它本來就深植在人類心靈之中。
