# 筆記卡
- 類型：角色分析總卡
- 角色：普萊德（Pride／傲慢）／傑利姆・布拉德雷
- 作品：《鋼之鍊金術師》
- 主題：傲慢、監視、影子、退化與重新養育
- 核心判斷：普萊德是七宗罪中最接近父親大人本質、也最具象徵性的存在。他的強大與傲慢幾乎達到極致，但最終卻被打回最脆弱的嬰兒狀態，從最像神的人造人退回到終於有可能學習成人的人類幼體。

# 角色定位
- 普萊德是父親大人製造出的第一個、也是名義上最強的人造人。
- 他在所有人造人中地位極高，幾乎是一人之下，其他人造人也必須聽令於他。
- 表面身份是大總統的養子傑利姆・布拉德雷，外表是天真可愛的孩子，實際上卻是心機極深、殘酷冷酷的高位監視者。

# 能力與象徵
- `影子本體`：普萊德的真正力量以影子形式存在，可延展、吞噬、切割、絞殺、防禦，幾乎無孔不入。
- `視覺與監視`：影子上的無數眼睛，使他不只具備戰鬥力，也象徵著全方位的監控與觀看權力。
- `吞噬與同化`：他能吞噬他人並奪取其能力，這使他的傲慢不只表現在態度上，也表現在對他人存在的直接侵奪。
- `光與黑暗的悖論`：他必須依賴光才能投出影子，但在完全黑暗或完全封閉的環境裡反而受限。這使他成為一個有趣的象徵：他看似籠罩一切，卻也必須依附某種外在條件才能存在。

# 角色特質
- `極端傲慢`：他不只蔑視人類，也拒絕以人類的價值尺度衡量自己。
- `高度自信`：即使被限制、被圍困、被攻擊，他仍維持極端冷靜與高傲，不輕易動怒或失態。
- `雙面性`：外表是無害孩童，內在卻是高度成熟且殘酷的非人意志，形成強烈反差。
- `尊嚴與矛盾`：他一方面看不起人類，另一方面在真正瀕死時卻試圖依附人類身體求生，暴露出其傲慢中的根本矛盾。

# 弱點與失敗
- `弱點`：強光、閃光，以及完全無法形成影子的密閉黑暗環境。
- `受困時的真相`：當本體影子被封住，傑利姆的容器就只是一個普通孩子，顯示其極端力量其實並不來自真正穩固的自我，而是來自外部條件下展開的陰影性擴張。
- `吞噬的反噬`：他雖能吞噬一切，卻也會受被吞噬者意識影響，這使他最終敗於自己原本以為能完全掌控的能力。

# 結局與角色完成
- 普萊德最終被愛德華擊敗，退化回胚胎般的弱小形態。
- 他成為唯一倖存的人造人，並由大總統夫人繼續撫養。
- 這一安排極具反諷與象徵性：最傲慢、最強大、最不把人類放在眼裡的存在，最後卻只能以最脆弱、最需要照顧的形態重新開始。
- 也因此，他的結局不是單純死亡，而是被重新養育的可能。

# 象徵分析
- `嬰兒原型`：普萊德的原初形態像一個可被兩指捏起的嬰兒，這與傲慢其實源自渺小與未成熟形成強烈呼應。
- `傲慢與幼稚`：真正的傲慢不是來自智慧完成，而往往來自尚未成熟卻自以為已掌握一切的狀態。
- `影子作為武器`：普萊德的武器是影子，本身也可看作對陰影概念的直觀化表現。傲慢要籠罩別人之前，往往也已先籠罩了自己。
- `重新成長`：他從最強退回最弱，反而首次獲得真正長成人的可能。這使他的結局帶有一種被剝除虛假全能後，重新學習成為人的意味。

# 與愛德華的對照
- 普萊德被愛德華親手打回原形，這一安排很有象徵意義。
- 愛德華一路從少年式傲慢、逞強與自負中成長，逐漸學會有限性、責任與承擔。
- 普萊德則是傲慢被推到極端後的化身，最終從高高在上的強者被迫退回到一個需要重新被教養的嬰孩。
- 換言之，愛德華是走出傲慢的人，而普萊德則是被傲慢吞沒、最後才有機會重新開始的人。

# 可直接放進分析的句子
- 普萊德作為最初也是最強的人造人，其角色意義不只在於力量頂點，而在於他將傲慢這一罪性推向極端後所暴露出的內在空洞與未成熟。
- 他以孩子形象偽裝，卻操縱吞噬一切的影子，這種表裡落差使其成為《鋼鍊》中最典型的幼小外殼包裹極端權力的象徵。
- 然而，普萊德最終被打回胚胎般的弱小狀態，顯示傲慢的盡頭並非真正的高大，而是暴露出其原本的渺小、依附性與未完成。
- 因此，他作為唯一倖存的人造人而被重新撫養，便不只是結局安排，而是一種帶有倫理與象徵意味的重置：最傲慢的存在，終於被迫從最卑微的位置重新學習如何成為人。

# 一句話濃縮
普萊德最深的反諷，在於他一生看不起人類，最後卻只能像一個真正的人類嬰兒那樣，重新被愛、被養大、被教會何謂成長。
