# 類型
論文資料

# 作品
《鋼之鍊金術師》

# 主題
小孩、被迫成熟、無力感、責任承擔

# 關鍵詞
孩子、天真者、孤兒、國家鍊金術師、活人武器、逃避、成長

# 核心判斷
《鋼之鍊金術師》中的「小孩」並非單純指年齡幼小，而是一種尚未完成倫理成熟的狀態。愛力克兄弟雖然擁有超越成人的鍊金術能力，甚至被國家制度吸納為「活人武器」，但作品反覆提醒讀者：能力、軍階與覺悟，並不等於真正成為大人。他們仍會逃避、逞強、誤判，以為只要「繼續前進」就能解決問題；也正因如此，他們的成長不是從小孩變成強者，而是從無力、逃避與天真中，逐步學會承認錯誤、承擔後果，並以不犧牲他人的方式負責到底。

# 核心文本
1. 阿姆斯壯少校阻止愛力克兄弟潛入第五研究所，明確指出「小孩子不能做這麼危險的事情」（Vol.3，頁107）。
2. 妮娜事件後，愛德承認自己仍想用錯誤方式解決無法解決的問題，並感到自己「根本就沒有成長」（Vol.2，頁76）。
3. 阿爾表示即使「違抗世界的趨勢」也想恢復成人類，顯示其欲望仍帶有天真而絕對化的色彩（Vol.2，頁77）。
4. 馬斯坦古一方面主張國家鍊金術師不分大人小孩，都必須承擔活人武器的覺悟；另一方面卻又選擇暫時隱瞞休斯之死，仍把愛德當作需要保護的孩子（Vol.9，頁34-36、59）。
5. 霍恩海姆指出愛德燒掉老家，並不只是破釜沉舟，也可能是像小孩藏起尿床床單一樣，想逃避犯錯痕跡（Vol.11，頁14）。
6. 愛德後來承認，面對妮娜可能被送往實驗室，他們只是把無法解決的問題延後，實際上什麼都沒做（Vol.12，頁43）。
7. 霍克愛不願讓小孩留在戰場上，但愛德主張作戰既由他們提議，就必須由他們善後（Vol.12，頁171-172）。

# 可引用分析
「小孩」在《鋼之鍊金術師》中具有雙重意義：一方面，它代表愛力克兄弟尚未成熟、仍需要被大人保護的事實；另一方面，它也揭示他們之所以會犯下禁忌，正是因為仍保有天真者與孤兒原型的心理結構。天真者相信世界應該可以被修復，孤兒則在失去母親後渴望重返被照顧、被愛的狀態。人體鍊成正是這兩種原型的失衡表現：他們不願接受死亡與失落，試圖用鍊金術抄捷徑回到失去的樂園。

因此，愛力克兄弟的「孩子性」並非作品要否定的缺陷，而是成長敘事的起點。他們的問題不在於年紀小，而在於尚未真正理解責任的重量：他們以為有力量就能修復世界，以為覺悟就是不回頭，以為只要把問題留到以後，就還有補救的可能。妮娜事件、第五研究所、休斯之死與庫拉多尼暴走，則一次次迫使他們面對自身無力，承認「什麼都沒做」也是一種責任。

馬斯坦古對愛德的態度尤其呈現成人世界的矛盾。他一方面將愛德視為國家鍊金術師，要求他承擔活人武器的現實；另一方面，當休斯死亡的真相需要告知時，他又退回保護者的位置，選擇暫時隱瞞。這說明在《鋼鍊》中，「孩子」不是可以被制度任意抹除的身分。國家可以授予愛德軍階與稱號，卻不能因此取消他仍是孩子的事實。

# 可直接放進論文的句子
- 《鋼之鍊金術師》反覆將愛力克兄弟置於「孩子」與「成人世界」的夾縫之中：他們具有國家鍊金術師的能力與責任，卻仍在心理上保有天真者與孤兒原型的未成熟狀態。
- 愛德華的成長並不是單純從弱小走向強大，而是從「以為自己能解決一切」走向「承認自己曾經什麼都做不到」，並在此基礎上重新選擇負責。
- 作品中的成人角色雖然承認愛德的能力，卻仍不斷提醒讀者他只是孩子；這種矛盾正是《鋼鍊》不同於一般少年漫畫之處：少年主角的強大不會取消其未成熟性。
- 從原型角度來看，愛力克兄弟的「孩子性」是天真者與孤兒原型的交會：他們既相信世界可以被修復，又因失去母親而急切渴望重返被愛與被照顧的狀態。

# 一句話濃縮
《鋼鍊》中的小孩不是沒有力量的人，而是尚未真正理解失去、責任與他人痛苦的人；愛力克兄弟的成長，正是從這種孩子性中一步步醒來。

## 主題延伸：孩子性同時也是希望的敘事功能
若從荒川弘在 vol.12 作者專欄的說法來看，《鋼鍊》中的孩子性不只是未成熟、無力與需要被保護的位置，也是一種創作上刻意保留下來的希望功能。正因為孩子尚未完全被現實馴化，愛力克兄弟才會在無望處仍然追問「還有沒有別的方法」，拒絕把犧牲他人當作理所當然。這使他們的成長不只是從孩子醒來，也是在現實殘酷之中保住一條能重新創造希望的路。

## 主題延伸：孩子性的終點不是全能，而是承認自己不再需要全能
從「小孩／被迫成熟／無力感」這條線一路走到結局，愛德真正完成的，不是從孩子變成無所不能的大人，而是承認自己不再需要無所不能。這使他的成長終點非常特別：不是靠更大的力量抵達成熟，而是靠放下最能定義自己身分的鍊金術，回到人之有限的位置。也因此，孩子性的甦醒最終不是被抹掉，而是被提升成一種能夠放手、能夠重新出發的成熟。
