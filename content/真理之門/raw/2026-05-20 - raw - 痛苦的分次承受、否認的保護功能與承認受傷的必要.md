# 資料類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019，頁64。

# 主題
痛苦的分次承受、否認的保護功能與承認受傷的必要

# 關鍵概念
痛苦、磨難、否認、分次承受、承認受傷、轉化信號

# 核心摘記
- Pearson 指出，人無法一次承受全部的痛苦與磨難，因此成長往往也不可能一步完成。
- 人必須一點一滴地學習放下，而這種漸進式歷程在心理學上與「合理的否認」有關。
- 她認為，否認並不完全是負面的，因為它具有保護功能，使人不致於一次被所有痛苦壓垮。
- 但這種保護並不是最終目的。每一次逐漸覺察到的痛苦，都可被視為推動生命向前改變的信號。
- 因此，真正的功課不在於逃避痛苦，而在於逐步認識它、承認它，並承認自己確實受了傷。

# 可引用分析
從 Pearson 這段論述可見，痛苦的面對並非一種全有全無的狀態，而更像是一種分階段展開的心理歷程。否認之所以存在，不只是防衛或錯誤，而是在某些時刻作為保護機制，幫助個體免於被過量的傷害感受瞬間壓垮。

然而，否認若始終停留不變，便會阻礙真正的轉化。Pearson 所強調的是：每次被意識到的痛苦，都是一個新的進展訊號，代表個體已經準備好再向前走一步，去承認某個先前尚無法承受的事實。

也因此，成長並不是「不再受傷」，而是能夠逐步辨識自己的傷、承認自己的傷，並把這些傷口轉化為改變生命方向的契機。從這個角度來看，受傷的承認本身就是英雄旅程的一部分。

# 與《鋼鍊》的關聯
- 這段很適合連到愛德華燒掉家的行動。
- 若從 Pearson 的觀點來看，燒家未必只是決絕或象徵切斷後路，也可理解為一種面對痛苦時的心理安排：愛德還無法一次承受失去母親、人體鍊成失敗、家庭崩解與罪惡感，因此他必須以某種激烈方式先處理其中一部分。
- 換言之，燒家不是表示他已完全放下，而更像是在「還無法全面承認所有痛苦」時，先透過一個具體動作讓自己往前移動。
- 這也可以佐證：愛德的成長不是瞬間完成，而是一路反覆在否認、前進、再被創傷拉回、再重新承認的過程中逐步發生。

# 可直接放進論文的句子
- Pearson 指出，個體往往無法一次承受全部痛苦，因此心理上的否認在某種程度上具有保護功能，使人得以分階段面對傷害與失落。
- 從這個角度來看，成長並不是立即全面接受痛苦，而是透過逐步覺察、逐步承認受傷的方式，慢慢走向轉化。
- 因此，角色的某些看似決絕或逃避的行動，也未必只是單純拒絕現實，而可能是在尚未能承受全部創傷時，先以一種可行方式處理其中一部分。
- 若應用於《鋼之鍊金術師》，愛德華燒掉故居的舉動，便可被理解為其尚未能全面承認家庭崩解與鍊成失敗之創傷時，所做出的激烈但具有心理保護性的前進動作。

# 一句話濃縮
否認不一定只是逃避，它有時是人暫時活下去的方式；真正的成長，則是在準備好之後，終於承認自己真的受了傷。
