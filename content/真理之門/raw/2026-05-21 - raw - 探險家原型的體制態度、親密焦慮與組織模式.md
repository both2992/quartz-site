# 資料類型
理論書籍筆記＋文本延伸

# 來源
Mark, Margaret；Pearson, Carol S. 著，許晉福、戴至中、袁世珮譯，《很久很久以前：以神話原型打造深植人心的品牌》，臺北：麥格羅‧希爾，2002，頁108、110、111。

# 主題
探險家／流浪者原型的體制態度、親密焦慮與組織模式

# 關鍵概念
探險家、流浪者、體制批判、個體性、親密威脅、平等機會

# 核心摘記
- 書中指出，探險家通常對體制抱持批判態度，但不同於英雄原型積極改造世界，探險家更傾向依照自己的人生觀活著。
- 對探險家而言，親密感可能威脅自我，因此他們常對深層關係顯得遲疑、笨拙或保持距離。
- 探險家式的組織重視個體性，不強調僵固規則與階級決策，並傾向追求較高的機會平等。

# 可引用分析
從這幾段說明可見，探險家／流浪者原型的核心，不只在於離開既有秩序，更在於維護自我完整性。因此，他們雖常對體制有所保留，卻未必會像英雄或鬥士那樣直接投入改革，而更可能選擇保持距離、依其價值自行行動。

這也說明了探險家在親密關係中的矛盾：他們並非沒有情感需求，而是因為太重視自我邊界，常把親密視為可能吞沒自己的力量，因此在面對家庭、愛或歸屬時容易顯得笨拙。

此外，探險家式的組織觀也很有意思。由於其重視個體性與自主，因此在群體安排上往往不依靠高度威權，而更傾向依能力、處境與實際需求來分配位置。

# 與霍恩海姆的關聯
- 這段很適合連到霍恩海姆。
- 他對亞美斯多利斯體制始終保持距離，甚至只是消極提醒比拿可「這個國家要出事了」，而不是主動投入政治操作，這很符合探險家／流浪者對體制的批判但不全面介入的姿態。
- 他對愛力克兄弟與家庭情感的笨拙，也可用「親密感可能威脅自我」來理解：不是沒有愛，而是太久習慣以疏離維持自身完整。
- 在地道分配眾人路線與隊伍時，他採取的也不是僵固階級式命令，而更像一種重視個體能力與平等分工的探險家式組織方式。

# 可直接放進論文的句子
- Mark 與 Pearson 指出，探險家原型通常對體制抱持批判態度，但與英雄原型不同，其不一定積極改造世界，而更常選擇依照自身人生觀生活。
- 此外，親密感對探險家而言可能構成對自我的威脅，因此其在深層關係中往往顯得遲疑、笨拙或保持距離。
- 若以此觀點分析《鋼之鍊金術師》的霍恩海姆，則其對國家體制的疏離、對家庭情感的笨拙，以及其較重視個體能力與平等分工的行動方式，都顯示其帶有鮮明的流浪者／探險家原型特徵。
- 因此，霍恩海姆的成熟不在於放棄流浪者特質，而在於從單純疏離走向能在保持自我的同時，重新與他人建立連結。

- 若你之後要寫霍恩海姆如何從局外觀者轉向有限度合作，這張卡很好用。

# 一句話濃縮
探險家不是不在乎世界與他人，而是總得先保住自己，才敢慢慢走向世界與他人。
