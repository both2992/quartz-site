# 資料類型
理論書籍筆記

# 來源
卡蘿・皮爾森，《內在英雄（第二版）》，徐慎恕、朱侃如、龔卓軍譯，立緒，2019，頁20。

# 主題
前五個原型的核心學習任務

# 關鍵概念
天真者、孤兒、流浪者、鬥士、殉道者、信任、哀傷、真實自我、改變世界、愛與放下

# 核心摘記
- Pearson 以發展歷程角度指出，英雄在不同原型階段有不同的學習任務。
- 天真者 學習的是 信任。
- 孤兒 學習的是 哀傷，也就是承受失落、承認傷痛。
- 流浪者 學習找出並界定真實的自己。
- 鬥士 要肯定這個真實自我，並進一步以此影響、改變世界。
- 殉道者 則學習去愛、去承諾，並最終放下執著。
- 這些原型不是孤立存在，而是英雄一步步發展與深化的連續過程。

# 可引用分析
從 Pearson 這段論述可見，原型並不只是不同性格類型的平行排列，而是英雄生命發展中一系列逐步展開的核心功課。每一階段都不是單純「扮演一種角色」，而是要學會某種先前尚未具備的生命能力。

這條路徑很有方向性：首先是天真者對世界的基本信任，其後是孤兒對失落與破碎現實的承受；接著，流浪者在失去原有依附後，必須重新找出屬於自己的真實位置；鬥士則進一步把這份自我肯定轉化為行動力量；最後，殉道者學會進入關係、承擔承諾，並放下對自我與結果的執著。

因此，原型的發展不只是由弱變強，而是從被保護、受創、尋找自我，到主動介入世界並學會愛與放下的歷程。這使原型分析不只可用來分類角色，也可用來辨識角色當前正處於何種生命功課之中。

# 可直接放進論文的句子
- Pearson 指出，英雄在不同原型階段各有其核心學習任務：天真者學習信任，孤兒學習哀傷，流浪者學習找出真實自我，鬥士學習肯定自我並改變世界，殉道者則學習去愛、去承諾與放下執著。
- 從這個角度來看，原型並非彼此孤立的角色分類，而是一條具有內在順序的成長路徑，標示出個體在不同階段所必須面對的生命課題。
- 因此，角色分析不應只問角色屬於哪一原型，更應進一步探問其正處於何種學習任務中，以及其是否已完成從前一階段邁向下一階段的轉化。
- 這也使原型理論成為理解角色成長、停滯與內在轉變的重要工具，而不只是標籤化的分類系統。

# 研究用途
- 很適合補進你前面關於天真者、孤兒、流浪者、鬥士、殉道者的理論段落。
- 也很適合直接套用在愛力克兄弟、斯卡、馬斯坦古等角色的階段分析。
- 若你之後要整理《鋼鍊》角色原型推進順序，這張卡會很好用。

# 一句話濃縮
原型的重點不只在「角色像誰」，而在「角色此刻正在學會什麼」。
