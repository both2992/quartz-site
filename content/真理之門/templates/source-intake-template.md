# 資料輸入模板

把新資料貼給 Codex 時，建議使用以下格式：

```md
- 資料類型：
- 來源網址或內容：
- 我的觀點：
- 我現在最關心的用途：
```

## 欄位說明
- `資料類型`：文章、PDF、影片逐字稿、社群貼文、研究資料、自己的筆記等
- `來源網址或內容`：可直接貼全文、摘錄、逐字稿，或附上網址
- `我的觀點`：你現在怎麼看這份資料、你特別在意什麼
- `我現在最關心的用途`：例如寫作、研究、教學、專案規劃、知識整理

## 建議做法
- 若你能直接貼全文或重點段落，整理品質通常最好
- 若只貼網址，可能會受限於抓取權限或來源可讀性
- 若你來不及整理想法，只寫一兩句也可以，之後可再補

## 範例

```md
- 資料類型：文章
- 來源網址或內容：https://example.com/article
- 我的觀點：這篇對知識整理流程講得不錯，但我更在意它怎麼落地到每天的輸入處理。
- 我現在最關心的用途：想整理成可用於寫作的主題卡與方法論筆記
```
